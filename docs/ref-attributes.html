属性リファレンス

オブジェクトの属性を、仕様書でどの種類のオブジェクトに定義されているかの順に並べた引き表。考え方は第1章を参照。

この並びは「定義の系譜」で、データの形ではない。実際のオブジェクトは、上の層から受け継いだ属性も含めて、属性をフラットに持つ。C_GetAttributeValue で層をたどる操作はなく、どの属性も型を指定して直接読む。

「確認」列に ✓ がある項目は、本サイトのサンプルが SoftHSM2 で実際の挙動を CI で確かめている。それ以外は仕様の表に基づく記述で、既定値や強制のしかたはトークンによって異なることがある。

「版」が空欄の属性は v2.40 で定義済み。v2.40 より古い版との違いは扱わない。

層の関係

あるオブジェクトが持つ属性は、根の Object からその層までの経路上にある属性すべて。たとえば RSA 秘密鍵は Object・Storage・Key・秘密鍵・RSA 秘密鍵の5つの層の属性をまとめて持つ。

  • Object
    • Storage
      • Data
      • Certificate
        • X.509 証明書
      • Key
        • 公開鍵
          • RSA 公開鍵
          • EC 公開鍵
        • 秘密鍵
          • RSA 秘密鍵
          • EC 秘密鍵
        • 共通鍵
          • AES 鍵
  • 書 アプリがテンプレートで書く
  • 黙 省略すると既定値
  • 生 トークン・メカニズムが作る
  • 読 読むだけ（書けない）
  • 粘 一方通行でしか変えられない
