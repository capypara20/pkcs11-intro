属性リファレンス

属性を「どの種類のオブジェクトに定義され、どこへ受け継がれるか」の系譜で並べた引き表。考え方は第1章を参照。

これは「定義の系譜」で、データの形ではない

仕様書上で属性がどの層に定義され、どこへ受け継がれるかを表す。実際のオブジェクトは、受け継いだ分も含めた全属性をフラットに持つ。C_GetAttributeValue に層をたどる操作はなく、どの属性も型を指定して直接読む。

あるオブジェクトが持つ属性は、根の Object からその層までの経路上にある属性すべて。たとえば RSA 秘密鍵は Object・Storage・Key・秘密鍵・RSA 秘密鍵の5つの層の属性をまとめて持つ。

バッジの意味

  • 指定するアプリがテンプレートに書いて値を決める
  • 必須作成時に書かないとエラーになる（条件は説明欄）
  • 省略可書かなければ既定値になる（既定値がトークン依存のものもある）
  • トークンが生成鍵生成などで、トークン・メカニズムが値を作る
  • 読み取り専用アプリは書けない。トークンが記録・付与する
  • 一方通行一方向にしか変えられない（戻せない）
  • SO のみTRUE にできるのは SO（セキュリティ管理者）だけ
  • v3.0 で追加その版で追加された属性。表示がなければ v2.40 で定義済み
  • ✓ 第1章で確認本サイトのサンプルが SoftHSM2 で挙動を CI 確認している
