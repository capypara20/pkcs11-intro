メンテナンス API リファレンス

トークンと鍵を保守するための PKCS#11 の関数を、作業ごとに引く表（24 件）。「確認済」の振る舞いは SoftHSM2 2.6.1 で確かめている。

このページの位置づけ

PKCS#11 の仕様に「メンテナンス」という区分はない。トークンの状態を読む、PIN を管理する、鍵を棚卸しする、属性を手入れする、退役させる、といった作業に使う関数を、作業の側から並べた。関数そのものの一覧は関数リファレンスにある。

同じ作業は、pkcs11-tool などのコマンドでもできる（中ではここに並べた関数を呼んでいる）。各行の右端からコマンドリファレンスの該当箇所へ飛べる。

保守で特に気をつけること

・一方向にしか変わらない属性がある（SENSITIVE・EXTRACTABLE・MODIFIABLE など）。固めたら戻せない。

・日付（CKA_END_DATE）は記録だけで、期限が来ても鍵は使える。期限切れの鍵を止めるのはアプリの仕事。

・初期化と削除は元に戻せない。先に移す・写すかを決める。

本物の HSM では

バックアップ・複製・監査ログ・ファームウェア更新・複数人の承認（M of N）などは、ベンダーの管理ツールや独自の API で行い、PKCS#11 の外にある。このページで扱うのは、PKCS#11 だけでできる範囲。
